## `> the interactive version`

<div align="center">

**This README is the flat fallback.** The real thing is a full 3D experience —
a WebGL hero with a starfield and floating code panels, tilt-reactive project cards,
an orbiting tech ring and a live-typing terminal.

<br />

### 🌐 [`profile-site/index.html`](profile-site/index.html)

<br />

| What's inside | |
| :--- | :--- |
| 🎇 **WebGL hero** | three.js starfield (5,200 GPU points), glowing wireframe core, orbiting particle rings |
| 🃏 **3D project cards** | pointer-tracked tilt, layered depth, sheen sweep, spotlight gradient |
| 🛰️ **Stack orbit** | 12 tech nodes rotating in real 3D space — hover to pause |
| 💻 **Live terminal** | types out `profile.json` character by character |
| 🖼️ **Real screenshots** | pulled from each repo's own assets, with designed cover art as fallback |
| 📴 **Zero CDN** | three.js and the fonts are vendored — works fully offline |

<br />

```bash
# run it locally
cd profile-site && python3 -m http.server 8000
# → http://localhost:8000
```
